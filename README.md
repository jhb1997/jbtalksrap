# JB Talks Rap

Rap album reviews at [jbtalksrap.com](https://www.jbtalksrap.com). The homepage is a playable sampler: each pad is a
record, the screen shows its score, and the Archive ranks every review. Review pages carry the full text with pictures
beside the paragraphs they belong to.

Plain HTML, CSS and JavaScript generated by a small Node build. No framework and no client-side rendering: every page
ships its text in the HTML, with its CSS inlined.

![The homepage: a sampler whose pads are the reviewed albums](docs/home.jpg)

## Commands

```bash
npm install
npm run build    # writes site/
npm run check    # Prettier and ESLint
npx serve site   # preview at http://localhost:3000
```

## Structure

```
content/          review text (reviews/*.md), titles and dates (manifest.json), scores and per-page data (site.mjs)
media/            source images: album covers, art beside the text (with CREDITS.md), textures, the share image
src/css/          site.css on every page, home-*.css, review.css, lost.css (404)
src/js/           site.js on every page, home.js (the sampler and the Archive), review.js (reading progress)
scripts/build.mjs reads content and media, writes site/: pages, resized images, fonts, share images, sitemap
scripts/lib/      the build's parts: content, images, assets, layout, home, review, 404, slab (the drawn floor)
site/             build output (not committed)
```

Review text is published verbatim. Scores, pull quotes and pictures live in `content/site.mjs`; the build fails if a
quote isn't word for word in its review.

## Hosting

`site/` is a static site: upload its contents to any static host. Pages are root-level `.html` files with relative paths,
except `404.html`, which uses root-absolute paths so it works at any missing address.
